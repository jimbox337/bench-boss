# Chrome Web Store listing

## Name

Bench Boss ESPN Sync

## Summary

Connect your logged-in ESPN Fantasy Hockey league to Bench Boss in one click.

## Detailed description

Bench Boss ESPN Sync securely connects the ESPN Fantasy Hockey league you choose to your Bench Boss account.

How it works:

1. Start ESPN sync from benchboss.pro.
2. Open the ESPN hockey league you want to connect.
3. Review the in-extension privacy disclosure and approve access.
4. Return to Bench Boss to confirm the league and import your team.

The extension reads only the current ESPN hockey league ID and the ESPN authentication cookies required to request private-league data. It does not read your ESPN password, unrelated cookies, general browsing history, or pages outside the supported ESPN hockey and Bench Boss domains.

Authentication information is transmitted only to benchboss.pro over HTTPS, used only for league synchronization, and encrypted at rest with AES-256-GCM. It is never sold or used for advertising.

Bench Boss is an independent fantasy hockey tool and is not affiliated with or endorsed by ESPN.
